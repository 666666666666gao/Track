## 同状态比较

从语义适配器输入处克隆当前RGB、Depth、未加残差的Mamba融合特征、初始化RoI和mask。当前参考帧按原规则输出并更新状态后，只在克隆特征上重新执行适配器和Center Head：

| 头部观测条件 | 保持与改变 |
| --- | --- |
| 同状态未加适配残差 | 对原参考状态的未修改融合特征运行原Center Head；不是独立原生STTrack轨迹 |
| 原完整文字 | 原类别与属性词向量 |
| 空文本 | 有效词槽使用CLIP空文本向量 |
| 类别保留 | 保留原自动类别，属性词向量为空 |
| 类别置换 | 仅替换类别词，属性保持为空 |

五个条件使用相同的当前视觉输入及历史状态，词槽与mask不变。记录原始score/size/offset图、Hann最高峰、按各自峰和固定参考峰解码的框、在参考峰的分数、是否超过0.75。诊断输出不写回bbox、query或模板。输入克隆在探测后逐元素检查不变。

每一帧参考输出都与原M58/M59封存预测比较；实际模板写入也逐帧核对。完成后才读取GT，报告当前时刻连续IoU、正确到严重错误及反向变化、换峰数、写入资格翻转、同峰写入翻转等。预先固定的平方根/平方变换仅统计保持框和RoI特征不变时的更新资格变化，不进行实际写入，不代表未来模板效用或新独立质量控制器已成立。
