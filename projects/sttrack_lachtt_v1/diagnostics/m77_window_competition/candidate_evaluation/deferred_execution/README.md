This live deferred controller waits on the exact PID, start time, command and working directory of the original M77 content controller, polling every240 seconds without acquiring a GPU. It leaves the original training, development and fixed-head content jobs unchanged. Only seed2027 and the prospectively fixed Category final are eligible.

After the original queue exits successfully, all15 frozen development conditions and all8 fixed-head lexical comparisons must pass before actual OPE/TraX prefix checks and low22 tracking. The inherited low22 conditions must also pass before the unchanged full-dataset pipeline can generate missing initialization captions or execute DepthTrack Test, CDTB and full VOT. All stages reuse the previously sealed single-bundle interface and protocol.

Failed experiment conditions produce an explicit no-promotion result. Execution errors preserve nonzero exits and logs. Neither causes a restart, relaxed gate or additional seed. Full-pipeline completion still requires inspection of actual target outcomes and final handoff; the server script never marks the thread goal achieved. The published evidence verifies CPU preparation and a real sleeping process only, not public metrics or independent model-review acceptance. See EXPERIMENT_TRACKER.md and master section5.147.
