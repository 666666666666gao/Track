# M121：首帧绑定的密集目标支撑与独立视觉范围修正

## 问题与推理职责

M119的实际整框观察内类别区域间隔为330/354开发状态正值，但类别最高峰250/495，且双方合格230次中164次定位变差；首帧池化余弦只有181/495。M118有拟合收益、无稳定内容收益。新原型因此不再给每个Top-10候选分别改写初始化文字，而在初始化目标区域绑定人审短语，让完整搜索256位置读取同一永久实例参照，并为每个位置产生可精修框。

A使用首帧RGB、Depth、Fused与CLIP各4×4目标局部token。当前全部搜索位置先读取这些首帧实例token；人审短语先读取首帧，再读取完整、已经实例条件化的当前搜索表示，随后当前搜索反向读取校准后的短语。原文字和首帧参照不可覆盖。当前解释是连续特征，不声称已有属性支持/冲突/未知真值。冻结原CLIP空间类别余弦作为已实测的输入证据，不能直接当部署分数。

B的框修正和定位质量只读视觉实例特征，文字仅影响目标支撑响应。视觉修正从M90真实全部256框出发，学习平移与尺寸残差；不永久锁死已有几何、不仅重排10个框。定位质量以新框与真实GT的IoU监督，与语义支持分开。最终选择为支撑概率×预测定位质量×原Hann，所有框、分数、质量和特征来自同一位置。

新增观察量只学习“GT框与当前实际图像窗口是否有几何交集”，不是物理出现/遮挡/身份概率。GT中心在外但框仍相交时，用交集的中心定义支撑点、回归仍指向完整GT，避免把还有部分目标的观察统一监督成纯负例。无效GT仍不造存在性标签。此阶段不提交tracker状态，也不控制模板或搜索；新分数不能直接套用旧0.75模板规则。
