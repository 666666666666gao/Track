## Additional model mutation and scope limits

1. **CLIP hooks are actual temporary mutable model state.** Each E:28–31 call registers six forward pre-hooks, calls encode_image, then removes those hooks on normal completion. The closure's `dense` list is call-local. Normal sequential branch observations return after hook removal; a concurrently overlapping call on the same CLIP object can see both sets of hooks. Thus frozen weights do not imply a mutation-free object or justify concurrent sharing. No concurrency wrapper, exception fallback or recovery code was added. [E:13–35; W:60–61]

2. **Pinned native top-level forward has no shown self-field assignment.** It does mutate the supplied query-list elements as above. M:94–104 contains in-place writes to local temporary aliases after concatenation at M:90–91; these are not evidence of an explicit write into `z_dict` slots. Newly created zero query Parameters are locals, not registered on self. No persistent hidden-state cache is exposed by this top-level interface. This does not prove all child modules/kernel implementations are stateless. [M:59–162]

3. **Exact native CENTER head and decoder do not introduce an explicit recurrent cache in their inspected forward paths.** H contains BatchNorm modules; native eval mode matters. H's in-place sigmoid operates on produced score maps; cal_bbox only reads maps and creates a result. D initializes parameters/buffers in its constructor and has no forward-time self-field assignment. The reviewed methods do not justify extra speculative state fields. [H:8–21,130–160,175–201; D:25–49,51–123; W:31; R:37]

4. **Unavailable authoritative implementation boundary:** G does not pin `vit_care.py`, the native `mamba.py`, `PreprocessorMM`, BaseTracker, installed CLIP/preprocessing internals, PyTorch, or compiled selective-scan/CUDA kernels. M explicitly calls backbone, TSG and MambaFusion. Historical A imports external selective-scan implementations, but A is not current-source proof. These dependencies were not installed/imported or runtime-inspected. No complete claim that the listed fields exhaust all deployed mutable model state is made. [G:4–56; M:10–13,73–76,100–101,142; N:4,14,21,31; W:5–8,32; A:18–32]

5. `frozen_digest()` hashes native and CLIP state_dict tensors only; it does not cover decoder state, trajectory lists, Python hook registries, configuration or random states. It is not sufficient evidence of branch isolation or K/K equality. The plan separately requires same GPU, weights, inputs and random state, followed by an actual first-12-event K/K check. No RNG use/equality or GPU determinism was tested here. [W:14–19,39–40; P:44,48,52]
