# M116之后的区域编码机制对照：待实现

M116普通CLIP空间token直接投影在人工文本下反而偏向外围，连t0也仅8/152得到正的类别区域差。这个观测与CLIP Surgery讨论的背景响应现象相近，但不是attention根因的因果证明，也不说明人审类别错了。

[CLIP Surgery原论文方法§3.2–3.3](https://arxiv.org/html/2304.05653)通过V–V一致attention与保留原路径的双路径结构形成密集表征，新路径跳过FFN；特征层另消除共同冗余。单句时采用空字符串参照。论文设置深度7，ViT-L/14使用16×16网格。[官方仓库](https://github.com/xmed-lab/CLIP_Surgery)提示公开demo与论文AMP设置有差别。当前已读原论文和仓库说明，具体模型源码尚未成功取回，不能称已完整移植或重现。

下一项可作固定机制对照：同一既有权重、同一原生crop、同一人审bank，比较普通空间token与作者双路径密集表征；全部预定读出和正负定位分组保留，不调seed/类别、模板阈值或测试GT。保持现有RGB-D信息与额外冻结RGB容量披露。单纯减Empty已有M84先例；作者双路径也不是项目原创。若区域证据有效，再做与视觉/generic匹配的A/B训练，不从热图或t0响应直接推断完整跟踪收益。

这是后续可检验方向，没有新源码部署、优化更新、C策略或正式指标。
