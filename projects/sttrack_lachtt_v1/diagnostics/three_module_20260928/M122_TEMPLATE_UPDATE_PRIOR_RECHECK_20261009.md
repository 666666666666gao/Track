# M122：模板更新直接先例核对（2026-10-09）

这是四项直接对照的原文/作者代码核对，不是系统性文献穷尽、正式新颖性判定或新实验结果。文献中的未来监督、强化学习更新和推理期历史核验均已有先例；下一轮需要证明既定C任务在当前RGB-D系统中的独立价值。

| 工作、作者及出处 | 方法与监督对象 | 已有证据和适用边界 | 与既定C的对应 |
|---|---|---|---|
| [UpdateNet，Zhang等，ICCV 2019](https://arxiv.org/html/1908.00855v2#S3.SS4) | 合成模板特征；论文以下一帧GT目标特征作MSE监督，多阶段预测缓存训练。 | 有固定作者代码commit；缓存生成含GT重初始化，公开目标数组的完整帧对齐尚未运行核验。 | 已有未来特征监督；当前C学习单动态槽位写入/保留对未来定位的差值，监督对象不同。 |
| [Recurrent Meta-learner，Li等，TIP 2019](https://www.microsoft.com/en-us/research/publication/learning-to-update-for-object-tracking-with-recurrent-meta-learner/) | ConvGRU更新模型，以后续搜索图分类损失和初始模型约束训练，采用截断时间反传。 | 已有通过未来匹配效果学习更新的实例；本次没有固定作者代码或数值更新间隔。 | 不能声称首次未来跟踪监督；当前C用同状态两动作的有限窗配对收益，无更新网络时间反传。 |
| [SiamRTU，Zhao等，TIP Vol30/2021](https://www.researchgate.net/publication/347158533_Siamese_Regression_Tracking_With_Reinforced_Template_Updating) | Actor-critic，IoU阈值奖励及折扣回报；8模板池每10帧选择一个替换槽位。 | 合作者上传完整论文；还含在线回归参数更新，没有固定作者代码；TD文本提取索引不作错误定论。 | 已有学习长期更新回报；当前C二元保留/写入、冻结AB、单动态槽位和显式W/K差值不同。 |
| [BackTrack，Lee等，arXiv 2023预印本](https://arxiv.org/html/2308.10604) | 候选模板在历史帧反向跟踪，以正反向框一致性决定是否接纳。 | 在线只看当前及过去，不需要未来GT；本次未核验同行评审版本或固定作者实现。 | 与未来收益教师不同，是推理期历史一致性对照；一致性本身不保证正确身份或未来收益。 |

UpdateNet作者实现固定在[7ade0364](https://github.com/zhanglichao/updatenet/tree/7ade0364c51d6460ef75781d37a12c8240c515dc)。其跟踪入口逐帧合成模板，改变SiamRPN分类/回归核，并没有独立的写入/保留概率。训练脚本的目标索引可以读到，但部分缓存生成依赖缺失，不能将论文的下一帧目标定义写成已执行的缓存逐项核验。ICCV 2019是本次核实的会议信息，先前任务提示中的CVPR应纠正。

现有学习型更新主要覆盖模板合成、模型更新和模板池选择；BackTrack则验证候选与历史轨迹是否相容。四者的作用、成本和监督不同，不能直接互换，也不能把它们的原任务成绩换算为本项目涨点。此次不复制新的推理规则，不修改正在运行的M122，也没有给C新增训练信号。

既定C最应先回答：当前框质量较好时，写入是否仍会损害随后定位；当前框质量相近时，配对未来收益标签是否比当前IoU标签更能指导写入。固定AB、相同输入/参数/预算的C-current与C-future对照仍是第一项直接机制检验。这里的差异是待验证任务设计，不能提前认定为新颖性通过或长期性能改进。

R1仍等待R0两版三数据集全部封存及新的结果审核。先完成同状态K/K复放一致性、状态隔离和实际成本检查，再保存W/K后32帧有效GT的平均IoU差值；未来信息仅产生训练标签。得到标签后可只读统计当前IoU与收益符号的四种组合，观察二者是否提供不同信息；尚未采集这些标签，也不据此改动已冻结计划。
