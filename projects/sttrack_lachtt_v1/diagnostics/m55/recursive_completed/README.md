## 配对结果支持什么

Clone相对原生有效帧均值+2.487个百分点，相对等预算Control+0.821个百分点；低重叠帧分别减少944和214。这说明在本次固定配对中，方向修正经过相同预算训练后确实改变并改善了部分定位，不能说修正完全没有收益。该结果没有文本或新增关联头，不属于语言创新。

同时，Clone的H10为91，高于原生75和Control86；flower03与mobilephone02新增失败，未通过冻结H10和成功序列保护要求。Control也损害了这两条，不能把所有共同退化都归因于两处clone。Clone序列等权均值0.671361低于原生0.684336及Control0.676652，说明有效帧汇总增益分布不均匀。只有一个配对seed，不宣称多seed稳定性或统计显著性。
