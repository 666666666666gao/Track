新增 `lachtt_initial_instance_alignment.py` 保留两次注意力：文字读视觉、各对象局部格点读条件化文字。initial 分支只从交互前 object20 读取视觉源；candidate 分支从各对象自身读取。`sttrack_initial_instance_observation.py` 准备用同一初始化图像及合法初始框提取参照，丢弃额外 forward 输出的 query。它尚未接入运行 tracker，现有 M56 和 M55 的绑定源码保持原样。

## CPU 验证结果

只使用 chair01_indoor 的 22 个已有 fit 事件，循环构成 32 样本检查批；每组 3 个临时优化步后丢弃模型。旧缓存中的参照实际来自 t1，不能将本次检查当作已完成 t0 提取或语义绑定正确性的证明。

| 检查 | v2 结果 | 结论范围 |
| --- | --- | --- |
| 四组参数与初始张量 | 484547，张量摘要完全相同 | 对照初始化匹配 |
| 零残差与原候选头输出 | 逐元素完全相同 | 候选头前向保真，不是完整原生轨迹保真 |
