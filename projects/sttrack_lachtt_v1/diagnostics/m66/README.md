## 无支持项当前还没有学成语义拒绝

Null的1,175×256=300,800个空间位置上，无支持槽概率中位数0.0015768、均值0.0016643、最大0.0196581，没有达到0.5的位置。486个正确选中峰的中位数是0.0021365，442个严重错误峰为0.0019423。至少在这批诊断窗口中，失败没有对应明显的无支持概率上升，不能把M65的整体增量解释为已经实现可靠语义拒绝。

Control对应统计仅是假设追加零logit后的数值，它的实际前向没有无支持槽，不能和Null混作同一个部署置信度。

代码还表明，即使语义context减弱，RGB和Depth局部特征仍直接进入delta残差。因此当前“无支持项”不等于把整个adapter回退到原生，也没有显式的属性真伪监督。下一项可检验问题是：直接监督目标区域与背景的支持关系，能否让该量具有实际意义；这是待设计实验，不是本轮结果，也不预先宣称可以解决所有出画恢复。
