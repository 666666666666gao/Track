## 新计算结果：仅Train开发22，不是正式Test/CDTB/VOT成绩

## 能支持的结论

M65 Null相同框的原分数比恒定分数高5.942060个F百分点，说明原置信度已经提供有效排序；GT重叠参照又比原分数高6.277051个百分点，说明相同定位轨迹仍存在分数判别空间。原生及Control相应oracle差值为9.006128、9.921019个百分点。这些差值不能推算为M68可取得的实际收益，也不能移植为Test/CDTB增益。

另一个值得保留的事实是：M65 Control的按有效帧mean IoU虽高于原生，其原分数Train长期F却低0.581385个百分点。长期评分包含初始化、无效GT帧的协议处理、全局分数阈值和序列等权P/R曲线，与此前跳过初始化和无效GT的mean IoU不同。不能用一个IoU均值代替最终PR验证。

三组恒定分数的结果还与“全部预测均被选择”时直接计算的序列等权P、R及其调和均值逐项吻合，误差小于1e-12。逐序列附表使用各序列自己的最佳阈值，不能简单平均后冒充上述全局阈值聚合结果。

## 对后续的影响

该结果支持继续检验M68预先冻结的语义支持分数读取，但M68在M67新head上的实际回放仍未运行。M67监督权重、训练预算和原晋升门均不变，M65因glass03保护失败而未晋升的结论也不改变。置信度变化本身不能改善固定框的VOT区域指标；目标仍是同一最终权重和运行配置通过三数据集。
