## 为下一步估计观察成本，而非宣称恢复容量成立

额外计算了一个纯几何参照：保持Null前一预测尺度对应的factor4边长，以约50%重叠平铺整幅图像，并包含边缘。所有窗口由图像尺寸和前一预测尺度决定，生成位置不使用GT；GT仅用于封存后的覆盖分析。

对于54个H10框外起点，平铺窗口在几何上覆盖全部54个目标中心，但只有45个能在至少一个窗口内完整覆盖GT框。全图网格对图内中心的覆盖是几何性质，不是模型识别能力。68个H10事件共需4,942个窗口，中位数32个，最大527个；所有216个去重事件共10,907个窗口。因此直接把全图平铺当作每帧运行策略，会有明显额外开销，后续应比较粗筛与少量高分辨率验证。

另有一个标注边界值得保留：glass03第313帧GT虽有效，其中心实际处于图像下边界之外，因此115个“有效性恢复”事件中，平铺网格对框外中心只能覆盖65/66。这不是搜索算法漏掉可见中心的证据。第657帧则重现既有M66几何：Null区域[126,284,135,135]不覆盖目标中心，factor7也不覆盖；该帧按当前尺度平铺需要45个窗口。
