## 文本如何被单独检查

每个影子观察都比较同一权重下的类别文本和全空文本，保留5槽、mask与padding。主路径始终保持类别文本，空文本影子不会改变后续主路径状态。因此，这次内容对照处于相同历史状态，区别于M69的两条独立完整递归。

对每种文字条件，先取全图粗搜索原始响应的NMS top10解码框；将各框中心映射到最近的高分辨率网格窗口，按峰值顺序最多取3个不同窗口。若不足3个，不添加补齐窗口。然后交叉读取类别/空文本条件下的精细候选，形成：

| 粗搜索选择区域 | 精细窗口的文字条件 |
| --- | --- |
| 类别 | 类别 |
| 空文本 | 类别 |
| 类别 | 空文本 |
| 空文本 | 空文本 |

这允许区分“文字改变了去哪里看”和“文字改变了窗口内定位”。但只有类别对空文本的差异，仍不足以证明类别语义正确；M69的固定替换类别对照是另一个必要证据。自动类别错误、同类实例不可区分等限制继续保留。

所有窗口均保存原Center Head对256个位置各自size/offset的解码框。已有decode_nms_candidates负责选择原始/Hann响应的top10位置，最终坐标统一来自原生cal_bbox与回映射，避免把两种浮点解码公式混用。随后只在封存后统计密集容量、top10容量以及按分数直接选择时的正确/严重错误数。最高分结果和oracle最佳候选均不接管轨迹。
