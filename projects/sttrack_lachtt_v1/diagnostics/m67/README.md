## 监督定义与因果边界

每帧先提交实际预测与状态，再经过原GT有效性检查。有效GT中心位于搜索内时，使用原生round/clamp约定得到一个中心正位置；GT框外扩一个特征格之后的区域作为负位置，其余位置不加该监督。正、负组分别求均值，再对存在的组平均，权重预先固定为0.1。

该损失使用原有属性证据和固定零logit的归一化：中心位置降低无支持概率，明确框外位置提高无支持概率。无有效GT的帧仍按原规则跳过，不把GT无效自动标成目标缺席。不用后续GT改选公共框或重置轨迹，不通过离散crop或跨时间反向传播。

这是框级弱监督，不能被解释为真实像素前景、属性可见性或caption正确性标签。自动类别错误保持原样。只有后续文字内容对照成立，才可进一步归因到具体词义。
