# M49：相邻帧运动、尺度与模板更新的实际验证

2026-09-05。依据用户最新提出的“目标相邻两帧移动应当有限，结合尺度变化检查模板更新”进行验证。本轮已完成；此前讨论的独立双分支后继尚未实现，没有把它当作已运行的 M49。

**结论：运动连续性有可用信息，很多失败确实伴随预测框自身的大跳动；直接用最近位置或速度外推决定选框，则尚未通过包含健康样本的对照。模板更新需要与身份和定位可靠性结合，不能单凭物体尺寸变化加快更新。**

## 范围、模型与测量口径

- 原生路径：M39 STTrack default，原 checkpoint、固定4个query、factor4搜索、factor2模板、每50步且置信度严格大于0.75时更新。没有改网络、权重、默认模板策略或文本输入。
- 完整覆盖低22的303条 multi-start 轨迹：220,180个跟踪步，另有303个初始化步。GT独立相邻帧对13,922；没有无效GT端点。本轮GT分析是标注框的几何变化，不能把像素/帧直接当成物理速度，也不能从矩形尺度变化单独确定遮挡、姿态或真实距离变化。
- 124个失败anchor对应72个不重复的相邻源帧转换。运动沿实际前向/后向评测方向计算；同时给出不重复的正常时间方向GT统计。anchor和相邻帧不是独立统计样本。
- 中心位移归一化分母为上一帧GT框的 `sqrt(w*h)`。尺度变化因子为 `max(sqrt(area_t/area_prev), sqrt(area_prev/area_t))`，例如1.1表示线性尺度相对变化不超过1.1倍，不是面积变化10%。
- 健康对照要求前后两帧的bounded VOT IoU均至少0.5，共147,109个anchor帧对。全部候选排名先封存，再读取GT标注。

## 模板更新：多数坏写入在失败之后

按原生50步/0.75条件重建2,929次模板写入；这重建的是确定性写入决策和写入时框，不宣称重新提取了每次模板特征。702次写入时IoU≤0.1，其中652次（92.88%）写入之前已连续低重叠至少10帧；只有1次坏写入发生在该anchor首次确认失败起点之前。

| 失败前最近一次可用模板的新增统计 | 数值 |
|---|---:|
| 写入时IoU≥0.5 | 117 / 124 |
| 写入时IoU≤0.1 | 1 / 124 |
| 仍使用初始化模板 | 35 / 124 |
| 模板年龄中位数 | 47.5个跟踪步 |
| 当前GT相对模板时刻GT的线性尺度变化因子中位数 | 1.189337 |
| 上述尺度变化因子超过1.5 | 18 / 124 |

健康帧模板年龄中位数36，尺度变化因子中位数1.092484，存在相关性，但不能由此推出更新频率是失败原因；健康帧也会使用很老的模板（95分位年龄185）。写入时覆盖正确不保证之后模板仍足以区分目标，也不能排除模糊或遮挡的影响。

当前模板裁剪边长约为 `2*sqrt(w*h)`，再缩放到128。因此目标在模板中的宽高约为 `64*sqrt(w/h)` 和 `64*sqrt(h/w)`；忽略整数取整和边界填充时，均匀缩放会抵消。需要区分“原图里的尺寸变化”“宽高比/外观变化”和“错误预测导致的框尺寸变化”。模板更新应优先检验后两者的可观测证据。

## 下一步与边界

1. 保留实际STTrack default模板适应与完整状态。M49没有上线一个新的运动限制、更新门或回退分支。M48的单次模板干预已证明，取消一次写入不能自动恢复已经走错的搜索状态。
2. 若继续验证运动，下一项应是让现有视觉实例匹配结合**因果速度残差及宽高变化的可靠性**，区分真实持续运动与突然跳向干扰物；上一位置不能无条件优先。M44已有单帧/两帧几何和缓存分类器，不能把同类几何再拼接一个MLP称为已证实的新方案。新的信息和递归收益要分别验证。
3. 模板更新实验保留默认更新为基线。触发依据应在DepthTrack Train中检查定位稳定性、当前与历史模板的实例匹配，以及尺度/宽高比变化；先隔离一项干预，不能同时改文本、搜索中心、阈值和网络。
4. 本地在线文本另作独立变量。诸如“从左到右第几个”的描述必须来自当前已观察到的图像，并带排序方向、同类对象范围和有效时刻；交叉或遮挡后序号可能变化，不能替代稳定身份。M49没有新VLM调用或文本提交，先前相对位置pilot的负结果仍保留。
5. 若改变网络或增加可学习模块，先在DepthTrack Train按序列划分训练；预测裁剪递归通过后再冻结低22评测，明显提升并保护成功序列后，才验证同一模型组合的DepthTrack Test、CDTB和完整VOT。M49没有新增正式EAO/ACC/ROB或PR/F，不拼接旧权重结果。
