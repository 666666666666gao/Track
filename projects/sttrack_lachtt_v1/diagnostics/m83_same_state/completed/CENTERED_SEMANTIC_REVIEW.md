**1. 数学上究竟保证什么**

令 x 包含同一次原生前向得到的 RGB、Depth、fused 搜索特征、固定首帧实例特征和完全相同的五槽 mask；q 是现有冻结 CLIP 文本输入，q0 是所有有效槽替换为既有 CLIP 空词向量、padding 原样保留的输入。记适配残差为：

```text
Dθ(x,q) = deltaθ(localθ(x,q))
原 M82：         Eθ(x,q) = F(x) + Dθ(x,q)
中心化候选：     Ēθ(x,q) = F(x) + [Dθ(x,q) - Dθ(x,q0)]
```

空词向量不是零向量。当前 M82 实际启用了 `null_support=True`，那只是 attention 中固定零 logit、零 value 的无支持选项；它不意味着 CLIP 空词输入的最终残差为零。当前 `local` 仍直接含 r、d，且整个残差头可学习，因此 M82 Empty 不能当作未适配原生。

中心化有两个确切性质：

1. 对相同 x、相同参数和相同槽结构，**Ēθ(x,q0)=F(x)**。它为所有参数值定义一个空词恒等点，不依赖把空词训练到某个近似值。
2. 如果 Dθ(x,q)=aθ(x)+bθ(x,q)，其中 a 在输出端是对所有 q 完全相同的加性项，那么 a 会抵消。等价地，给 D 加上任意与 q 无关的输出函数，不会改变中心化输出。

第二项不等于识别、剥离了模型中的全部“非语义成分”。这里选的是一个特定空词锚点，而不是对所有词向量取均值，也不是从数据中唯一识别出“视觉”和“语义”的因果分解。空词分支本身是学习中的、依赖当前视觉和首帧实例的函数；它不是冻结原生教师。

实际残差头是：

```text
zq = W1 localθ(x,q) + b1
Dθ(x,q) = W2 GELU(zq) + b2
Dθ(x,q)-Dθ(x,q0) = W2 [GELU(zq)-GELU(z0)]
```

`local` 中的 r、d 虽在两支相同，但经过 GELU 后不能按输入坐标直接消去。例如 GELU(a(x)+u(q))−GELU(a(x)+u(q0)) 仍依赖 a(x)。RGB/Depth 投影、视觉主效应与词输入的非线性交互都会继续影响输出。**可以说“去除以空词为参照的共同加性残差”，不能说“输出只剩正确词义”或“视觉适配被完全消除”。**

还存在直接的非空指示偏置反例：D(x,q)=a(x)+h(x)s(q)，其中 s(q0)=0，而所有已见非空词都有 s(q)=1。中心化结果仍为 h(x)，所有非空词完全相同。现有网络可学习或近似这种行为，无需新增显式 gate。因此严格 Empty 恒等并不能单独证明不同类别内容被正确利用。

**2. 哪些梯度被抵消，零初始化是否还能学**

`semantic_spatial_adapter.py:18-20` 将最后一层 W2 和 b2 都置零；M82 只训练 adapter，support loss 为 0，native/backbone/head 冻结。以下为该实际损失路径的解析结论：

| 参数或路径 | 中心化后的任务梯度 |
|---|---|
| 最后 Linear 的 b2，768 维 | 代数上精确抵消；恒为零 |
| 最后 Linear 的 W2 | 来自两支隐藏激活的差，通常可学习 |
| 第一个 Linear 的 W1、b1 | 两支 Jacobian 之差；经过 GELU，不一般抵消 |
| RGB/Depth/text 投影、LayerNorm、slots、modality、绑定层 | 不一般抵消；是否有信号取决于两支差异与上游梯度 |
| 冻结 CLIP、原生 backbone/head | 仍按原协议冻结 |
| 全空输入 q=q0 | adapter 的全部任务梯度为零 |

若 g 是损失对增强特征的梯度，单位置 W2 的梯度形如 g·[GELU(zq)−GELU(z0)]ᵀ；b2 的梯度是 g−g。**在零初始化的第一次 backward，W2 可能得到非零任务梯度，b2 为零，所有更早 adapter 参数的任务梯度也为零，因为反传需要乘 W2。** 在 W2 更新后，前面的参数可获得梯度。不能保证每一个样本的首步 W2 梯度必定非零。

这里的“精确抵消/零梯度”指代数和精确算术，不承诺浮点共享参数累加逐位为零。报告落盘期间，主执行者另报告其新候选 CPU 合成检查：非零权重下 Empty 前向与 F 逐值相等，但 RGB/Depth Linear 和 LayerNorm 的多路径梯度累加残余最大为 1.4551915228366852e-11；text/slots/delta 梯度为零，最初的全参数逐位零断言因此失败。该数值来自执行者消息，本审阅未独立执行或读取该检查的完整结果。它不构成 Empty 可学习任务信号，也不改变“不跑独立 Empty 训练”的结论；应保留失败记录并明确数值容差，不能通过 detach 或额外回退分支制造通过。

相比原 M82，原路径首步的 b2 也可以学习；中心化永远移除了这个输出偏置自由度。保留现有 state_dict 可以仍存储 289,154 个参数，但其中至少 768 个参数对任务输出无效；扣除此项最多有 288,386 个可能有效参数，不能声称两种函数有完全相同的有效自由度。没有必要为此增加另一套配平模块或单独 bias 消融，披露即可。

**两支必须共享同一个 adapter，并都保留对 θ 的梯度。** 冻结 q0 的 CLIP 编码不等于 detach Dθ(x,q0)。若第二支 detach，前向虽然仍满足相减，但 backward 只优化第一支；尤其 q=q0 时会出现前向恒等而人为产生非零任务梯度。这不是该差分函数的正确训练，不能用它制造“Empty 训练有学习信号”。

严格空词还要求实现顺序为先算 `residual = delta_q - delta_empty`，再算 `enhanced = fused + residual`。不要把浮点运算写成左结合的 `(fused + delta_q) - delta_empty`，也不要从两张非线性 head 输出相减来代替特征差分。当前 adapter 只有末行使用 fused，未来用原 forward 的零 fused 输入取得 delta、避免复制整段交互实现，在源码结构上可行；本轮没有实现或验证该写法。当前 adapter 是无 dropout 的 LayerNorm 路径，具体新代码仍需验证空词输出恒等及上述梯度契约，解析证明不是已经完成的 GPU 测试。

现有 AdamW 有 weight decay。即使全空输入的任务梯度为零，参数也可能因衰减而变化；这不构成从 Empty 数据学习了跟踪能力。不能用参数变动或跑满步数作为有效训练证据。

成本依据仅作计划参考：已有 M82 Category 训练回执为 13,120.7 秒，约 3.64 小时/臂；一个 Category dev22 推理回执为 1,763.3 秒，约 29.4 分钟。新差分多一个 adapter 分支，不能直接沿用或机械乘二这些时长，应由其短预检实测吞吐估算。mask 对照和原生参考本身不需要新增优化训练。

**7. 空词回退与独立原生闭环必须分开表述**

设当前 Category 已走到状态 s_t^C，其中含预测框、crop、query 和模板历史。中心化空词输出是 H(F(s_t^C))，它与同状态未适配 head 一致；独立原生跟踪器则位于 s_t^N，通常 s_t^C≠s_t^N，所以 H(F(s_t^C)) 不等于独立原生当帧结果。先前由非空词造成的错误 crop 或模板，不会因当前残差归零而自动撤销。

只有**从相同首框、相同初始化开始全程 Empty**，并保持相同运行数值与状态更新路径，才能由逐步归纳得到整个 Empty 轨迹等于原生：本帧输入状态相同→原生特征和解码相同→提交框、query、模板行为相同→下帧状态继续相同。未来具体实现应验证这个契约；本轮只给出条件证明，没有宣称新实现已全程验证。

M82 的 KL 教师本来也是学生当前状态上的原生读出，且只是训练期在 GT 有效、中心在 crop 内、原生 IoU≥0.5 时启用；它不是独立原生历史。其空间归一化不保持绝对 score，也没有对 size/offset 或全部非空递归作严格约束。中心化可以把 Empty 恒等强化为结构性质，不能因此升级为“错误文字自动回退安全”或“恢复独立原生轨迹”。
