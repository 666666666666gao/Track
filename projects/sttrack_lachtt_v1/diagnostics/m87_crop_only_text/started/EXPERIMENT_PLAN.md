# M87：仅目标紧裁剪的初始化类别协议对照

日期2026-09-21。M84为封存结构/训练对照；M86已验证152条来源链并完成非独立助手初筛。本实验先冻结新输入协议，再生成、编码与核验；训练与开发结果不得反过来用于改prompt、重选caption或人工改词。M86判断不作为新caption标签。固定seed2027，不增加多seed，不下载或更换Qwen/CLIP/STTrack权重。

主问题：减少整帧背景/持有者信息后，类别指代是否更贴近初始化目标，固定差分适配器的训练收益是否改善。这里的主因素是“文字生成协议”，包括只输入紧裁剪及只要求类别；不是单独隔离全图移除与prompt改写的贡献，不声称模型创新。

新协议：152个相同t0图像、协议框、旧裁剪整数范围。Qwen2.5-VL-3B仅接收目标紧裁剪这一张RGB图，min/max像素预算沿用旧目标crop的128/256乘28²。固定英文指令只要求短小lowercase category；内容不明确时可输出object；不给序列名、数据集类别、旧文字、M86判断、性能或后续帧。greedy、不采样、最多48输出token；所有原始回复先保存再严格解析，不重试改词、不补默认词。共152个生成调用。

输入结构保持：同一冻结CLIP ViT-L/14编码，原有5槽、mask、padding不变，仅替换槽0类别向量，其余有效槽仍是原空文本向量。Empty向量固定沿用旧bank；无效槽仍为旧padding。生成词为空或解析不合格时明确停止。新类别若为object仍是非空语义条件，不等同Empty。

同权重内容组：new Category、原M84旧Category、Empty、新Category的确定性不同字符串捐赠Swapped。Swapped按既定序列顺序循环找第一个不同类别字符串，仅捐赠槽0，接收者mask等不变；不同字符串不保证语义矛盾或错误。所有映射在跟踪之前封存。

训练保持M84：从同一原始零初始化checkpoint训练一个Category臂；冻结STTrack/Center Head，仅289154存储参数的共享双支差分adapter；Raw竞争与可靠同状态native KL不改。130条拟合序列相同顺序、186694次跟踪调用、5798次优化；学习率/累积/截断/状态协议/模板/Hann等逐字段保留。评测固定最后完整遍历checkpoint，不挑中间loss。不训练纯Empty臂。除输入协议外不加区域绑定、记忆或恢复模块。

前检与执行：生成前检查旧来源/模型/图像及crop绑定，原始回复及全部bank在训练前封存。新bank用旧mask/empty/padding的逐值检查；类别编码可复用旧原始CLIP bank中完全相同字符串的向量，任何新字符串使用同一冻结编码器的原流程编码。保存每个字符串来源，禁止按结果选择向量。完成96帧真实拟合集、3次优化的训练入口检查，检查有限梯度/损失、原生冻结、训练后空词恒等；前检权重丢弃，不用于正式训练。

四组开发22均完整递归并封存后再加载GT计算指标。训练和选择只用DepthTrack Train。报告旧M84和M82、原生参照，按帧均值、宏均值、低重叠、H10、逐序列、内容LOO以及原生零H10损害。M82作历史参考，不新增必须逐序列支配所有历史版本的要求。

预定接受条件：相对M84旧协议训练，均值严格增、宏均值不降、低重叠不增、H10不增（4）；相对原生同4项及原生零H10保护（5）；同权重new相对old同4项（4），相对Swapped同4项（4）；Empty逐序列原生一致（1）。共18项全部报告，未通过则不自动晋升。M86助手初筛不充当语义真值，原词/新词优势不得直接称正确类别理解。自动类别仍可能错误，语义判断与性能判定分开。

预算：生成约3–6分钟，CPU编码约1分钟，前检数分钟，训练4–5小时，四组开发利用两卡约1小时。原M84封存对照复用，不重训。总跟踪调用预算与M84相同，不声称caption生成额外成本为零。控制器在真实退出0后衔接评测，轮询约240秒或接近预计完成时观察，不因SSH失联重启。

三个正式数据集仍须同一最终checkpoint/文字协议/运行策略通过。此次不直接生成外部全量caption或运行正式评测；只有开发证据支持后另行冻结外部输入和评测。两个Qwen保留；新训练只新增小adapter最终/latest权重，不复制大基座。
