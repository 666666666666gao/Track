# M87完成态自动收集

用途是完成态数据收集，不是新实验、性能门或额外训练。固定等候当前控制器PID 25357（run_m87.sh）；每240秒检查真实进程。控制器消失或成为zombie后，必须读取controller.exit、训练、四组递归和分析退出码全部为0，再读取完成态结果。进程消失而没有正常退出证据时明确失败，不重启训练，不生成完成声明。

维持原18项条件，不以初筛语义判断、训练loss或局部结果决定通过。收集最终完整遍历权重、全部训练序列/采样日志、四组22条递归预测及回执、实际规格/代码/文字bank、开发GT（只在全部预测已封存和原分析结束后）、结果与源文件引用。保留失败条件的真实值。最终权重元数据和有限性留给完成后的完整审查，不在等待期间读取活跃latest权重。

补充功能核验：M87 Empty完整输出与已封存M84 Empty逐帧框、分数比较，单独报告；M84 Empty与独立原生全轨迹一致的证据在已完成M84审查中。此比较称“M87 Empty对封存M84 Empty”，不称新增独立原生推理，不更改M87冻结的指标级Empty门。

只使用CPU，显式禁用CUDA；不生成caption、不解码外部图像、不更新主模型、不读取后续开发GT直到原分析完成、不发送外部消息、不自动运行正式数据集。收集结果无论18项通过多少都保留，不按通过与否选择导出。私有包保存在服务器，后续下载和完整审阅后再同步交接文档及公开去除图像/坐标的结果。
