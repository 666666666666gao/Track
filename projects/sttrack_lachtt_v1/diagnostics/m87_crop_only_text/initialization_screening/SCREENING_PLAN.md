# M87 新类别的初始化观测初筛

本轮在 M87 训练进行中执行，只读冻结的152条新自动类别和同一首帧目标图像。不得读取后续图像或按开发/外部指标修改文字；本轮不修改bank、prompt、训练源、检查点选择或18项评测条件。该核查独立于训练效果判定。

逐条以初始化图像与协议框中的视觉证据，记为supported、conflicting或uncertain。supported表示类别与可见对象相容，不等于细粒度身份唯一或所有属性正确；conflicting要求可见目标明显不属于该类别，或类别明显指向框外/其他对象；细节不足、边界含多个候选且无法确认指代、细分功能无法从外观判断时记uncertain。宽泛object若出现，只能表示兼容且无具体类别辨识力，单独计数。

图表使用匿名顺序编号及新类别，隐藏序列名、fit/dev划分、旧词、M86旧判定和全部跟踪指标。每项显示首帧目标红框图和真实紧裁剪。必要时查看同一首帧原分辨率；不看后续帧。助手已具有项目上下文，且曾看过部分旧初筛，因此不称独立盲评或人工真值。

先封存152项新判断与简短可见理由，再连接历史M86记录报告类别字符串变化和支持状态的配对分布。M86与本轮均属助手初筛，配对变化不作生成器真实准确率、统计显著性或跟踪收益证明。所有正反例保留；判断不写回训练文字。
