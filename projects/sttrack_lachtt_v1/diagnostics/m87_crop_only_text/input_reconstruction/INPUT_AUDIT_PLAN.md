范围：152条已冻结caption记录对应的同一初始化RGB观测。仅在CPU重新执行现有图像预处理与tokenization，不加载Qwen权重，不调用generate，不训练、不改词、不变更当前M87。

核查：原图SHA与裁剪边界绑定、当前caption源与spec绑定、图像数量、历史保存的image_grid_thw、聊天模板图像占位与实际image token数量、输入tensor有限性、patch布局逆变换后的RGB像素一致性、静态图像的两个时间patch相同。保存本次环境/库源码及模型processor配置的哈希。预定展示010、028、042、062、068、071、105、128八项重建图，覆盖已发现的错词与可支持例子；这是事后机制诊断，不是无偏质量抽样。

历史生成时未保存pixel_values，本次是相同绑定图像、源码、配置的预处理重建，而非历史输入tensor逐字节回放。历史grid可作实测交叉验证，不能证明当时所有内部张量或生成状态完全相同。通过只排除本次可复现预处理中的通道、布局、空图和占位问题，不证明模型读懂图像、不证明caption准确、不解释全部错误原因。
