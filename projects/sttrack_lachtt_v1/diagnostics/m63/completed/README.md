## 条件差值与可支持的结论

固定原类别定位，更新判断从C改成S（CS对CC）：平均IoU下降3.6227个百分点，低重叠帧增加1,311，H10增加3；写入由197变为246。22条中4条均值提高、7条下降、11条相同。cup13下降44.3192个百分点、低重叠帧增加891；cup10却提高8.2245个百分点。实际写入数是各自递归轨迹的统计，不能把这组差值解释成统一更新频率的效应。

固定替换类别定位，更新判断从S改成C（SC对SS）：平均IoU下降1.0548个百分点、低重叠帧增加316，但H10减少6。22条中7条均值提高、4条下降、11条相同，说明失败段数与持续低重叠长度并不等价。

定位文字的作用也依赖写入通道：固定C写入，C相对S定位提高2.5120个百分点；固定S写入，C相对S定位按帧均值反而下降2.1656个百分点，但序列等权均值提高2.2642个百分点。四单元描述性交互差分CC−CS−SC＋SS为4.6775个百分点，没有多seed显著性检验，不能把类别收益按一个固定比例拆成定位贡献和模板贡献。

M61的同状态证据与M63的完整递归共同支持：文字能够通过写入接口改变后续轨迹，定位与写入之间存在明显状态依赖。它们不支持“文字仅靠模板起作用”，也没有证明把分数拆成两个通道就自动获得部署收益。本轮最好的联合条件仍是CC。

## 长期损害证据

审计发现CS在cup13的[1140,1160)、[1161,1181)及mobilephone01的[1367,1381)、[1384,1418)四个区间持续低重叠，共88帧，而相同定位文字的CC在这些对应帧全部IoU≥0.5。两条轨迹都从第50帧首次写入分叉，以上区间距首次分叉1,090—1,334帧。

这说明只观察提交后两帧或十帧可能漏掉后续损害；期间还有多次状态演化和写入，因此不是已识别第50帧那一次写入的孤立因果效应，也不能把无效GT直接解释成遮挡或出画。
