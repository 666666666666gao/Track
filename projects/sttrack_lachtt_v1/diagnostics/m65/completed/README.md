## 配对设计与覆盖

Control与Null均使用原生STTrack冻结底座、相同零残差参数初始化、289,154个学习参数、相同130条DepthTrack Train拟合序列与顺序。训练和开发均保留自动类别槽0，属性槽替换为空文本向量，原5槽、mask和padding不变。每组186,694次真实预测裁剪调用、5,798次优化，只有初始化使用GT框；每帧先提交自己的预测与状态，再计算GT损失，无跟丢重置、无跨时间或离散crop反向传播。

唯一结构干预是属性注意力增加固定零logit、零value的无支持项；没有新增学习参数。当前实现允许语义context被减弱，不等于已经得到有监督保证的“语义不匹配检测器”。两组都没有在线caption、候选关联头、当前Depth可靠性模块、新模板阈值或TSG Clone。
