# M59 固定同一文本权重的内容干预诊断

M58 v2已完成，按帧IoU有收益，但H10为78，未通过≤75的晋升条件。**M59是对这个未晋升版本进行的训练集内内容诊断；M58原门槛及原条件队列的not_run记录保持不变。**这里没有新架构、训练、权重选择、公开数据集评测或自动晋升。

本次固定M58文本final、全部视觉权重、槽mask、初始化RGB-D参考、默认模板及query策略，只替换文字内容。它回答的是：观察到的收益和损害，是否真的随文字内容变化？M58文本与同预算纯视觉采用不同训练权重，那一比较本身不能回答同一权重对语义的敏感性。
