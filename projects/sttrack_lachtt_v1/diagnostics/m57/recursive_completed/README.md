## 配对结论

初始化文字组相对原生mean IoU下降5.6891个百分点，相对同槽初始化视觉对照下降6.0512个百分点，相对候选自身文字组下降1.0121个百分点；低重叠帧增加1740，H10增加5，并使原生零H10的mobilephone02新增失败。该组7条均值上升、12条下降、3条相同。

候选自身文字相对同结构视觉查询有1.7639个百分点的均值收益，但两者都低于原生；初始化视觉组比原生高0.3621个百分点、低重叠帧减少344，H10却由75增到94。这些混合结果不能挑选成语言晋升。词义增量的差分之差为-0.078150906571（约-7.8151个百分点），未支持这版初始化绑定改进。

四组有相同参数量、初始化、顺序、预算、t0及有效槽结构，补上了M56有效槽数不同的控制缺口；但仅一个seed，视觉查询组仍保留文本槽结构元信息。比较不同训练组不等于固定同一权重替换词义，完整递归的固定权重空文本／错配干预未执行。历史七条文字复核来源限制继续适用。

本结论限定于当前候选RoI结构、1511个原生状态训练事件与固定预算，不能推断所有初始化实例绑定或语言引导都无效。该模块仍在STTrack生成候选之后运行，没有训练语言引导的密集响应，也没有完整身份传播或语义视角记忆。

## 分叉和持续损害

封存四组完整预测后，对全部88条轨迹进行后验诊断。首次bbox差异（最大坐标误差>1e-6）全部发生在首次非默认改选；该项覆盖本次实际前缀，不是任意状态下的等价性证明。各组所有H10区间与冻结统计一致。

- mobilephone02：初始化文字组第7帧首次改选，原生IoU=0.774563、改选IoU=0.566184，当时两框均仍覆盖目标；全程11次改选，随后第497—700帧出现204个连续低重叠帧。首次分叉到该段相隔490帧，不能把后续损害全部因果归于第一次动作。
- egg：第87帧首次改选时两条路径IoU均为0，不能称为从正确框切到错误实例；全程均值0.734778→0.499927，低重叠帧523→1425，H10 9→18。
- flowerbasket：第一次改选在第336帧，该帧GT无效，不能断言改选框的IoU；均值0.762025→0.311582，低重叠帧123→555，而H10仍为3，说明只看失败段数会漏掉失败持续时间的增加。
- ghostmask：均值0.716086→0.820801、低重叠帧193→20、H10 3→0，是本版明确的局部收益；它没有抵消其余序列损害。

上述时间关系不是取消某次动作的干预重放。记录的score是跟踪输出响应，不是经过校准的实例身份概率。原生轨迹独立保存；NONE回到当前被修改轨迹的候选0，不能恢复独立原生轨迹。
