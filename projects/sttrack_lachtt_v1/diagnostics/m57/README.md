# M57：初始化实例绑定的同槽2×2实验

四组等预算训练和完整递归均已结束，共132520帧。初始化文字主实验mean IoU为0.595335，低于原生0.652226和同结构视觉对照0.655847；H10由75增至80，七项晋升条件均未通过。本版停止晋升，未运行低22或三个数据集全量。见[完整终态、逐序列指标与损害诊断](recursive_completed/README.md)。

## 这轮检验什么

四组都使用同样的t0初始化参照、5个可学习槽、同样有效槽mask和484547参数。只比较短语读取各对象自身视觉还是初始化实例视觉，以及保留真实词义还是使用CLIP空串与可学习查询。文字先读取视觉，各对象自己的局部RGB-D格点再读取条件化短语。

它是新增候选RoI交互头上的实例条件化实验，没有把语言接到STTrack主干候选生成前，也没有实现持续干扰物ID、属性可见性检测或身份—视角记忆。视觉查询对照保留了描述的槽结构元信息，不能称为完全没有语言元信息。NONE依然退回当前递归路径的候选0，不能冒充独立原生分支。

## 已完成的数据与运行核验

原生checkpoint为cacbd799115be1aaeb049cee0db89270851e3b6dd68997553b4c2c31c1104f98。代码来自已绑定的M55 Control原生源码快照，再加入已有M56模块及M57模块，共172个来源文件；没有使用M55微调权重。已知原生TSG别名语义继续保留，不把两次方向调用描述为独立证据。

85条Train序列只读取各自合法初始化RGB-D帧，额外前向的query丢弃。参照按运行时half().float()协议分成63条fit和22条development文件，共约4.2MB；训练只载入fit银行和1511条fit标签。仅在RAM将旧原生缓存references[:,0]替换为t0，旧候选、动态参照和缓存文件不修改。

实际四组运行类在chair01的1002帧全部执行，强制原生候选0推进，在22个既定事件逐项核对候选、动态／初始参照、几何、分数、previous_choice、文本和mask，全部与训练装载精确一致；公开框也精确一致。耗时258.928秒。它是强制原生路径的接线验证，不能当作学习后四组完整递归保真或性能结果。

## 完整递归与下一步

GPU0依次initial_text、initial_visual，GPU1依次candidate_text、candidate_visual，每组都让自身预测框生成下一帧搜索图，使用因果t0和默认query／模板更新。首帧参照在每条序列重新计算并逐元素对照已采集t0。独立冻结的原生轨迹用于最终对照。

完整轨迹指标要等四组132520帧预测全部封存后才读取逐帧GT统一分析。上述静态缓存标签是在所有权重封存后读取，未传入递归推理，也未改变配置。后台分析器每240秒等待两个队列，只有全部正常完成才执行已冻结分析。

主实验initial_text须同时满足mean IoU相对原生+0.002、相对initial_visual与candidate_text各+0.001，词义增量差分之差>0，IoU≤0.1帧/H10不高于原生，并保护原生零H10序列。四组全部报告；通过后再做固定权重完整递归文本反事实，之后才冻结VOT低22。低22改善后才以同一base/head/runtime/text协议跑三个完整数据集。详见冻结计划。
