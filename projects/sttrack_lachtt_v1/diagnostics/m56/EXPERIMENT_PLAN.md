# M56：稳定属性文本与候选局部 RGB-D 的交互

用户已明确主要创新是文本融入强原生 STTrack，允许幅度不大但可归因的提升。本轮将 M55 定位为独立底座检查；M56 使用当前原生权重与 M44 已封存的真实预测状态特征，不等待采用 M55，不把原生 full127 成绩算作语言收益。

## 唯一新增假设

保留稳定属性的短语表示，让属性读取候选局部 RGB-D，再把当前视觉证据反馈给局部匹配，可能比将所有属性先合并为一个向量更能区分相似实例。这是待验证假设。

旧实验已经使用过整句 CLIP 表示、池化首帧模板及 response residual；其中有过极小语言增量，也有语言贡献为负的短窗结果。M42 的空间信息保留也没有单独通过增量假设。新实验的变量是属性表示与局部格点之间的可学习交互，不能以“增加 attention”代替语言证据。

## 模型改动

原生 STTrack 的 ViT/BSI、TSG、Mamba Fusion、Center Head、factor-4 搜索、4 个历史 query 和默认模板更新均保持原设置，语言不参与候选生成。使用同一个 NMS top10 集合及各峰自己的 size/offset 解码框。

复用 M44 候选集合头，在 `cell` 投影之后、对象特征展平之前增加一个块：

1. 每个候选或模板的 RGB/Depth 局部格点保持为 `2×16×32`。
2. 属性短语经冻结 CLIP 编码为 768 维，再投影至 32 维。
3. 属性 query 对局部格点做一次交叉注意力；得到含当前视觉上下文的属性表示。
4. 局部格点读取这些属性表示，经零初始化输出投影加回原格点，然后继续原候选集合 Transformer。

真实构造检查确认新增参数为 35,648，总参数为 484,387。零初始化用于验证接线时的原头保真，不代表训练后不会改坏轨迹。默认候选0、NONE处理、几何、模板写入和 query 更新不另改；NONE仍返回当前策略状态下的候选0，不是独立原生轨迹回滚。

本轮稳定文本在初始化后保持不变；随图像变化的是匹配表示。没有实现在线 Qwen 写文本或当前真实物体 ordinal。多个候选框可能属于同一物体，禁止把候选编号当成物体序号。

## 文本来源与对照

复用已有 DepthTrack Train 首帧审阅标注的 `annotation.category` 和 `annotation.stable_attributes`，不读取初始深度、遮挡、动态位置等状态字段作为文本输入。原始标注、短文本材料化收据与当前63/22划分均绑定 SHA。部分标注具有历史跨帧审阅记录，应如实保留来源，不把复用标注称为本轮新生成的在线描述。

属性表由类别短语和已有稳定属性短语构成。CLIP ViT-L/14 仅作为冻结文本编码器，不额外读取候选图像。第一版不新增 Qwen 注释，以隔离表示与交互的变量。

三组使用完全相同的新网络、初始化、拟合样本顺序和优化预算：

| 组别 | 文本输入 | 检验内容 |
| --- | --- | --- |
| attributes | 类别＋各稳定属性分别编码并保留 | 属性局部交互 |
| pooled | 对完全相同的短语向量取平均，作为一个有效输入 | 属性空间是否有保留价值 |
| empty | 冻结 CLIP 的空字符串表示 | 新参数和视觉交互本身的收益 |

空文本是一个有效输入向量，不使用全遮罩注意力。所有组填充到同一属性槽数，填充槽不参与读取。训练后还对 attributes 固定权重测试空文本、划分内打乱属性，以及有证据支持的同类别冲突属性。冲突对照的覆盖范围必须单独报告，不能把未经确认的不同描述统称为错误属性。

打乱映射在每个划分内按序列名称排序，采用第一个使所有短语集合均发生变化的循环移位。冲突对照仅覆盖具有同类别、非空且不相交的已标注颜色词的序列，采用名称排序最前的可用供体；它表示与既有首帧标注冲突，不是独立验证的每帧错误描述。映射在训练前封存，结果在相同覆盖子集上配对比较。

归因限制：pooled和empty只有一个有效key，第二次注意力成为各局部格点共享的广播；同参数量不等于同有效注意力容量。attributes优于pooled首先支持短语粒度与局部交互的联合设计，不能单靠该对照宣称纯语义收益。开发打乱映射中15/22换了类别、10/22换了短语数；冲突对照覆盖9条，其中3条也改变短语数。因此预先规定同时报告全覆盖结果、短语数相同子集，以及打乱对照中类别相同／类别和短语数都相同的子集；不能把完整打乱结果全归因于细粒度属性。

## 训练与评测边界

沿用 M44 的63条 fit、22条 development；拟合1511个候选对，开发590个候选对。开发集被反复使用，不能称为全新未见测试。训练复用 M45 监督：默认候选 IoU≥0.5 时保留默认标签，否则选择达到0.5的最高IoU候选，均无有效候选才标 NONE。匹配损失只监督有目标标签的对应，不给未标注干扰物编造身份。

三组从相同 seed2026 初始化，固定20轮、batch32、AdamW lr3e-4、weight decay0.01、梯度裁剪1.0，共960步／组，仅采用最终轮。训练新增交互块与候选头，STTrack及CLIP冻结。可先在 CPU 完成数据和反向检查；完整训练启动前需封存具体代码、数据及执行设置。

本轮缓存来自原生 STTrack 的预测轨迹，上一候选选择均为0。它没有增加关联头自己改选后的状态数据，也不宣称解决M52所检验的训练—部署状态差异。准备脚本解析既有混合标签文件后仅物化1511条fit数值标签，训练脚本只读取该fit文件；开发数值评估在三组最终权重全部封存后进行。

缓存指标只做诊断。完成固定训练后，从相同初始化分别运行全部22条完整因果轨迹，与独立原生 STTrack及同预算对照比较。使用既有连续矩形 IoU：初始化与无效 GT 不计入均值；无效 GT 中断 H10 连续低重叠段。只有预测封存后才读取后续 GT 计算指标。

本轮预设递归晋升条件：attributes 的有效帧 pooled mean IoU 比原生至少高0.002，比 empty及pooled两组分别至少高0.001；低重叠帧数和H10段数不超过这三组；原生H10为0的序列不得新增H10。全部逐序列结果、伤害和文本消融均需报告，不能仅报告平均文本相似度或最有利窗口。

通过后才冻结低22评测。低22相对 M39 default 要求 EAO和ROB各至少增加0.2个百分点、ACC降低不超过0.1个百分点、失败数减少、7条原生无失败序列保持无失败。它是多次使用的开发集合。随后验证同一个 base＋语言头＋文本生成／读取策略在 DepthTrack Test、CDTB和完整VOT上表现。本轮小幅增益门不代表已经达到原三数据集数值目标，也不替代最终语言消融。

## 当前状态

已实现独立模块与原候选运行类接线；85条首帧属性已编码为冻结CLIP短语库，共173个唯一短语（含空串），最大5槽。85条中7条具有历史跨帧或裁定复核来源。唯一初始化框差异为cat04原GT超出360高图像底边5像素，旧文本裁剪框恰为图像边界裁剪，已记录，未改动GT。

真实chair01训练缓存的检查已通过：共享初始参数精确相等，零残差logits与affinity精确相同，填充槽不影响结果，短语置换最大浮点误差约3.34e-6，三步真实标签反向传播有限且属性交互层获得梯度。检查权重已丢弃，没有保留为训练结果。尚未获得M56正式训练权重或跟踪指标。启动前由机器可读spec绑定预算、数据、代码、文本对照映射和晋升门，之后不按开发或低22结果修改本轮设置。
