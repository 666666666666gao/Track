## 可归因的结论及限制

属性组分别比池化和空文本组高6.754、4.789个mean IoU百分点，低重叠帧也更少。这是已测得的完整递归方案差异，不能继续用静态快照结果说三个方案在递归中几乎一样。但属性组没有达到冻结的原生+0.002门槛，H10和成功序列保护也未通过；低重叠帧仅从7397减到7356。

三组训练参数、初始化、顺序和预算相同，但pooled/empty只有一个有效文本槽，attributes有多个。因此上述差异仍混合了短语语义和有效注意力结构差别；尚无本次固定属性权重的完整递归空文本／错配文本对照。已有静态错配未显著下降的负证据仍保留，不能宣称纯语言内容已带来4.789个百分点收益。

这条路径在候选RoI层进行文字—局部RGB-D交互，语言没有进入STTrack候选生成；默认模板更新保留。它尚不是初始化实例绑定、持续身份传播或语义视角记忆。七条历史跨帧／裁定复核文本来源的限制也没有因本次递归完成而消失。

## 首次分叉与延迟损害

封存全部三组预测后才运行后验诊断。全部66条实际轨迹中，首个bbox差异（最大坐标误差>1e-6）均发生在首个非默认改选帧；无改选的路径保持一致。这里没有发现观测路径在首次改选之前已改变原生框。该检查只覆盖这些实际前缀，不是所有状态下的等价性证明。

- egg：第6帧首次改选候选2，独立原生IoU=0.905881、改选框IoU=0。全程519次非默认选择，H10由9增到21，低重叠帧523→1546。

- mobilephone01：第374帧首次改选时两框仍覆盖目标（0.898858→0.669636）；后续低重叠帧207→435，H10 5→6。
