# M56 审阅处理

审阅模型已按用户要求改为 `gpt-6-astra`，`reasoning_effort=max`。本轮属于同模型家族的 Type-A 建议审阅，不称为跨家族独立验证。原始问题、回复和 SHA 单独封存，历史 GPT-5.5 审阅记录不改写。

启动前审阅给出 WARN，没有发现阻止三组 fit 训练的具体 FAIL。已落实的范围如下：

- 当前 development 递归入口核对三组最终 checkpoint、base 权重、训练 spec、文本库 SHA，以及序列到文本库的映射；继承的运行类负责正常默认模板和 query 状态演化。原始包装器本身不承担全数据集来源核验。未来新数据集需绑定该次初始化文本 manifest 与同一编码协议，不能把新文本库硬要求为训练文本库同一个 SHA。
- pooled/empty 单有效文本槽会使第二次注意力成为共享广播。同参数量成立，但有效注意力容量并不相同。因此这组实验检验短语粒度与局部交互的联合假设，单独的三组结果不足以证明所有收益来自属性语义。
- 固定权重的打乱实验会同时改变部分序列的类别和短语数；冲突子集的9条中有3条也换了短语数。训练前固定了分层统计：全覆盖、短语数一致，以及打乱实验中类别一致和类别／短语数均一致的结果。所有干预与伤害都报告。
- 真实缓存 contract 证明有限反向、零残差接线保真、填充及置换性质，并记录三步后参数变化。AdamW的weight decay也会使参数改变，因此参数变化不独立证明每个子分支都有非零数据梯度；它不代表正式训练或语言性能已经通过。
- 训练器只读1511条fit数值标签。准备器解析过既有混合标签文件后过滤，这一点已保留。7条历史跨帧／裁定复核文本的来源不隐去；本轮也没有加入关联头自己改选后的预测状态数据。

以上为根代理根据源码与收据完成的处理记录；审阅没有实际执行GPU递归。M56是否优于原生STTrack，仍由冻结后的完整22条轨迹和后续评测决定。

第二次接线审阅确认静态反事实、递归权重／文本绑定、GT解析顺序与晋升门代码一致，并指出GPU0协调队列成功标记写在等待pooled和分析之前。已将`queue_gpu0.exit=0`移到分析成功之后；任何提前失败由外层控制器保留实际退出码。该修改发生在队列首次启动之前，不改变训练权重、预测或指标算法。原始审阅保留它看到的旧队列版本及该WARN，不改写为审阅人已复跑新队列。

完成态CPU验收另由Astra读取实际包完成：36个私有文件全部字节／SHA一致，34个公开对应文件一致；三组正式权重、60条训练epoch记录、初始化及事件顺序摘要通过，六种静态模式与119份逐序列统计独立重算一致，均值浮点差不超过4.98e-8。判定PASS，含既有范围WARN。审阅明确定位attributes的三次严重破坏为`colacan04_indoor@264`、`egg_indoor@46`、`egg_indoor@3547`，没有将当前结果改写为语言优势；也确认首次排队时成功标记问题已经关闭。审阅未执行模型、GPU递归或原始候选GT重叠重算。
