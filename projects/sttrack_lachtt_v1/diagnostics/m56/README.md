# M56：稳定属性与局部RGB-D交互的配对试验

三组训练、静态诊断及完整22条递归均已完成。属性组完整mean IoU为0.653400，优于池化0.585857和空文本0.605514，但原生为0.652226，H10由75增至86并新增mobilephone02失败，未通过冻结晋升门。有效文本槽结构仍不同，不能单独归因为词义内容。见[完成态及全部逐序列报告](recursive_completed/README.md)。

## 固定训练

- 同一个原生STTrack底座，SHA `cacbd799115be1aaeb049cee0db89270851e3b6dd68997553b4c2c31c1104f98`；没有载入M55权重。
- 63条DepthTrack Train fit、1511个原生轨迹候选对；三个484387参数头分别从同seed2026起点训练20轮、960步。共享初始化、事件顺序与预算一致已在完成记录中验证。
- 新增35648参数用于短语读取局部RGB-D、局部格点读取条件化短语。STTrack、CLIP冻结；默认模板更新保留；没有在线Qwen、ordinal、持续ID传播或身份—视角记忆。
- 85条文本有7条历史跨帧／裁定复核来源；本轮不构成严格自动首帧注释协议的证明。原始图像、GT、缓存、CLIP bank和权重保留在私有服务器／审阅备份，未随本目录分发。

## 590个重复开发快照上的结果

这里含495个有效GT事件；其余95个事件按既有M45缓存口径记零IoU／NONE。原生候选0的平均IoU为0.440274、正确268个。这不是33130帧完整递归的mean IoU，更不是VOT EAO。

| 同预算模型 | 平均IoU | IoU≥0.5 | 严重原错→正确 | 原正确→严重错 |
| --- | ---: | ---: | ---: | ---: |
| 独立属性短语 | 0.450518 | 275 | 7 | 3 |
| 同短语池化 | 0.451725 | 277 | 7 | 0 |
| 空文本 | 0.450667 | 276 | 7 | 0 |

attributes固定权重改用空文本后为0.449481；整套文本错配后为0.450700，实际选框只改变7/590个。9条同类颜色词冲突子集共225事件，真实文本0.472446、冲突文本0.468270；其中6条同短语数子集144事件，真实0.499052、冲突0.492527。局部正信号存在，但不足以抵消主比较未优于空文本／池化、完整错配不下降的限制。

pooled／empty为单有效文本槽，注意力容量与多槽attributes不同。已报告同覆盖、同类别／同短语数的预定分层，详见完整静态结果；不能把该三组比较单独解释为纯属性语义贡献。

## 递归与后续范围

三组固定最终权重已各完成22条、33130帧因果轨迹，GPU0先attributes后empty，GPU1跑pooled；独立原生轨迹按SHA复用。所有进程与分析正常退出，预测封存后统一解析GT。退出码0表示运行成功，性能晋升门未通过。

完整递归门为：attributes有效帧均值相对原生至少+0.002，相对empty、pooled分别至少+0.001；低IoU帧和H10段不增加，并保护原生H10为0的序列。静态结果不用于跳过这项已冻结比较，也不触发自动低22或全量评测。最终底座仍待M55配对验证；换底座需重采集、重训练语言模块。

## 复核与文件

`source/`保留服务器脚本名称；`train.py`也是静态／递归脚本导入的绑定工具。脚本中的环境、数据与checkpoint路径来自冻结实验，重放需相应配置并保持来源核验。新模型和运行类在项目`overlay/`中。

运行`python verify_cpu_report.py`可复核公开事件行的聚合、训练完成记录、初始化／顺序配对与对照覆盖；该脚本不重新计算原始候选与GT重叠，也不包含私有权重字节。
