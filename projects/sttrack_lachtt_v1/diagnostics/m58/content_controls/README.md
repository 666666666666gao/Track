## 冻结条件及解释范围

启动必须先满足原M58主门：text相对原生和同预算visual的均值收益、低重叠/H10和原生成功轨迹保护全部通过。内容主门另要求原始自动文字相对同权重`empty`、`mismatch`的pooled mean IoU分别至少高0.001（0.1个百分点）。所有组都报告mean、低重叠帧、H10、逐序列变化和首次框分叉；没有只选正例。

`category`与`attributes`为预设的次级对照，不自动构成独立属性贡献结论。原文字来自Qwen自动生成，带已记录的误认；“自动类别相同”未人工确认同一物理类别，供体属性也未逐项确认对目标为假。跨类别错配不能证明同类属性消歧，空/错配文字还可能超出训练文字分布。因此固定权重敏感性必须与同预算视觉训练对照共同解释，不能仅凭错误文字让结果变差就宣称方法成立。

22条仍是反复使用的DepthTrack Train开发集；本阶段不训练、不给生成器看后续帧，也不生成新caption。使用同一固定text final，不复制STTrack底座或保存额外训练权重。五份初始化银行（原文字及四组干预）共6376643字节，只留服务器。
