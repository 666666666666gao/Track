M58 v1新训练器使用floor分配中心热图单元，而预训练STTrack的原生监督采用round；其坐标也没有直接复用原生transform_image_to_crop。冻结底座后，这个差异会惩罚原本正确的高响应。此处是本次新增训练器的实现问题，不能用来解释M55、M57或全部历史改造的负结果。

v2直接复用原生transform_image_to_crop和round，将中心落到最近的0..15可表示单元。边界约束属于有限热图的赋值定义；此次已有训练采样状态中未观察到round到16的边界例子，不能把它表述成已测得的边界收益。当前诊断证明的是中心标签对齐，未证明新版本会提高完整轨迹指标。
