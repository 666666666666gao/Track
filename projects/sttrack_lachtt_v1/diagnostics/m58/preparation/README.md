# M58：密集语义交互原型与原生接线验收

M57候选头完整递归未通过后，本阶段实现一个289,154参数的初始实例语言/RGB-D模块。它在TSG及Mamba融合之后、原Center Head之前作用于全部256个搜索位置，能够影响响应、size和offset，尚未进行真实数据优化或验证学习后的性能。原生STTrack权重与默认模板更新仍是基线。

## 实际结构

输入为RGB/Depth/fused搜索token、初始化目标自己的2×4×4 RoI、最多5个CLIP类别/属性槽及有效mask。各短语分别读取初始化RGB/Depth局部token，形成与目标绑定的参照；学习两模态权重后计算密集搜索属性证据，再以小型残差作用于融合特征。残差末层零初始化。新增参数仅289,154；没有把候选头、在线Qwen、运动门、额外模板策略同时接入。

这是一项待验证的结构假设。模态softmax不是有真值保证的深度可靠性检测，属性注意力不是已经标注验证的部件定位；当前也未实现持续目标ID或语义视角记忆。普通语言/视觉注意力及密集语义响应已有近邻方法，不能把本原型接线本身作为已成立的新颖性或性能贡献。

## 已完成的检查

CPU合成输入检查验证：零末层的输出逐元素等于原融合特征，合法属性分数有限，模态权重和为1；两步合成MSE更新后RGB、Depth、text投影都有非零有限梯度。合成步骤仅检查接线，没有训练数据或保存可晋升权重。

真实GPU验收使用同一个原生权重，同时独立运行OFF、未训练零残差TEXT、未训练零残差VISUAL三条路径。VISUAL用CLIP空文本替换词向量，保留相同槽数/mask，不能称为完全没有文本结构元信息。

共306图像帧、918条路径帧状态、909次track调用，核心用时47.35秒。OFF预测框与此前独立原生轨迹前102帧逐元素一致；TEXT/VISUAL的框、响应、query、全部模板和裁剪图与OFF一致。初始化额外提取RoI产生的query不写回跟踪状态。160个源文件在验收前后核验，退出0。

这些是限定样本和零输出状态的接线保证；它不保证训练后无害，也不是低22或三个数据集指标。`integration.json`与`data_inventory_summary.json`保存更早阶段的状态字段（当时GPU验收/集成尚未完成）；应以随后绑定同一源代码的`native_parity_result.json`作为完成态证据，不回写旧快照。

## 训练数据范围与下一步

原始DepthTrack Train有152条，沿用已多次分析的22条开发集，其余130条作为拟训练集（原63条加67条）。所有首框有效，RGB/Depth帧名匹配；toy07_indoor_320有已知39行GT尾部无图像，继续遵守既有明确数据契约。公开清单仅保留计数及SHA，不分发图像、首框坐标或GT。

正式训练尚未启动。下一步准备仅初始化帧生成的类别/属性文字，并实现按预测框裁剪、时序递进的训练片段，保留等参数、等预算文字/空文本对照。M55使用的是GT扰动裁剪、整网微调，不能把其采样器称为真实预测裁剪训练；M52的一轮策略快照扩充也不能替代因果片段。训练预算、采样和晋升条件应在查看新开发结果前冻结。

原生base、两个Qwen及当前正式头均保留。磁盘已清理退役实验权重，后续只保存必要检查点。没有新的独立Astra/max审阅PASS；此前代理额度限制仍未解除，执行者验收不冒充独立审阅。
