## 首帧文字的来源和局限

使用已保留的本地Qwen2.5-VL-3B，对152条Train序列的第一张RGB及其初始化目标框生成类别+最多4个属性。模型只看同一首帧的标框全图和目标crop，没有序列名、类别提示或后续图像。一次贪心输出，保留原始文字；Qwen3-8B继续保留但没有用于这个视觉注释步骤。

第一版因模型返回Markdown包裹的JSON而退出1，0条有效记录，原回复已保存。第二版只接受这种已经观察到的固定包装，prompt和生成设置没有改变；152条全部完成、退出0，用时186.32秒。随后CLIP CPU冻结编码用时59.72秒，130训练/22开发文字银行分开，5个槽；48条有4个有效槽、97条有3个、7条有5个。

这些是自动生成、含噪声的描述，不是经人工保证准确的语义真值。执行者检查了seed2026抽取的24条训练及全部22条开发的首帧crop，发现bag05被描述为hand、包装物被描述为phone、花朵被描述为insect等错误，也有背景/瞬时词进入属性。没有用后续图像或跟踪结果重写文字。本轮保持冻结自动协议，以其真实噪声检验增量；不能把失败全部归因于网络，也不能提前把文字标成准确可靠。该检查不是独立审阅或152条完整准确率测试。

## 训练实际如何推进

每条序列只用首帧GT初始化；从第二帧起按时间顺序，用当前模型预测的bbox、query和默认动态模板生成下一帧输入。每帧先解码并提交公开预测，再将当前GT交给损失。GT不选择公开候选、不扩大crop、不重置失锁状态。

底座前向在no_grad/eval下执行，密集残差与冻结Center Head的局部反向计算只更新新增模块。中心热图用focal；GT中心所在单元的框用2×GIoU+5×XYXY L1。无效GT不产生损失但轨迹继续；目标中心在搜索区域外时，用全负中心热图并关闭框回归。每32个已观察帧积累梯度，按有效监督帧平均；AdamW lr=1e-4、weight_decay=1e-4、梯度范数截断1，固定一个完整遍历，最多5896次优化。

这是真实预测裁剪状态上的局部模块训练，但不是跨裁剪/离散选框的端到端反向传播，也没有BPTT。训练中的参数会更新，部署则固定最终权重；该区别如实保留。没有加入在线caption、运动规则、额外模板阈值或GT恢复。

训练接线先在fit的chair01验证102帧与生产语义路径完全一致，含第100步写入后的读取；再在96帧执行3次工程优化，RGB/Depth/text投影都有有限非零梯度，底座所有参数和缓冲区SHA不变。工程权重未保存或用于正式初始化，正式两组从同一个未训练零残差状态开始。
