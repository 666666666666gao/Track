## 收益集中与持续损害

1. 相对原生，文本按序列平均IoU提高10条、下降12条，但在ball07、car01、colacan01等较长困难轨迹上有较大收益；删除任一单条序列后，按帧均值相对原生仍为正。这支持新adapter和训练方式具有整体容量，不能把6.04pp都归给文本。
2. 相对纯视觉，文本提高12条、下降10条，收益仍不均匀。分别移除beautifullight01、cup13或mobilephone02中的任一条，剩余集合的按帧文本增量会转为负。这是固定结果的影响度诊断，不用于删序列、改权重或选新的门槛。
3. 文本H10区间总帧从原生7160降至5173，但存在6段共217帧的文本H10区间，独立原生在每个对应帧都IoU≥0.5。相对纯视觉也存在6段共246帧的同类损害。因此既有长失败缩短/分段的现象，也有明确持续损害，不能只用段数变碎解释。
4. 相对原生的上述6个损害区间都紧接无效GT帧。这只说明失效集中在标注有效性恢复后的窗口，不能仅凭GT无效便判定具体遮挡、出画或旋转原因。需要看实际观测或做因果干预，不能拿这一后验条件作部署触发。

典型退化flower02_wild：原生0.650547/100低帧/2H10，文本0.218057/346/6；同预算纯视觉为0.656891/99/1。文本在该序列的[414,520)零基帧区间持续106帧低重叠，而原生每帧均正确。相反，cup13文本0.815044而纯视觉0.473216，并保住了纯视觉损害的mobilephone02。两组头经历不同优化和递归状态，尚不能判定这些差异是具体词义直接造成。

## 下一步及边界

本次冻结M58 v2不晋升，原内容队列保持not_run记录；不放宽H10门，不重写历史实验结论，不直接跑VOT低22或全量。下一项有针对性的训练集内诊断是固定这个文本final权重、mask与运行策略，对空词、仅类别、异类替换、同自动类别属性替换进行完整递归，判断词义是否真的改变正负轨迹。它需要另立诊断方案，不能将M58原本未获准运行的条件队列伪装成已经通过，也不能凭诊断结果让M58自动晋升。
