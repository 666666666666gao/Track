# M76四个既定失败起点的图像与响应对照

本图从已封存的M76四个起点生成，没有新增跟踪、优化或seed，也不改变正在训练的M77。原帧、GT文件、重放文件和响应均核验SHA；CSV中四种同状态头的16行IoU/峰值与原完成态结果逐值一致。

每行从左到右为原RGB图、搜索区域RGB显示缩放、原始响应和Hann乘原始响应。绿色为GT，品红为实际Hann top1，橙色虚线为当前同状态上的raw top1，白色虚线为搜索区域。响应图全部共用真实0到1色标，没有逐图归一化。帧号为零基，图像文件名为帧号加一。放大的RGB区域是可视化裁剪，不声称是保存的网络输入张量。

book06图中有外观相近的书本，预测落在前方较大的书本区域，GT指向其右后方实例。cup08的GT区域靠搜索图上沿，部分在crop外，实际预测落在下方白杯区域。两例的密集解码容量不足已在原M76报告中确定。

cup10图中上下两个红杯相邻；egg图中有多个相似鸡蛋。两例原始响应选中了GT实例，Hann后转到另一位置。此图直观支持M77对最终空间竞争进行监督的动机，但无法证明具体文字导致改峰，也不能将一个正确raw top1当成完整递归救回。取消Hann伤害健康帧的原负结果仍保留。

这些是事后选定的四个Train开发事件，不是无偏失败分布或VOT结果。文字具体贡献继续由M77固定权重内容对照判断。PNG和PDF交付服务器及桌面document目录；Git收录渲染源码、精确绘图数组、数值CSV与收据，未复制数据集图像文件。
