# M84：以空词为参照的中心化语义残差

计划日期2026-09-20；实现与前检通过后才封存启动。只使用seed2027，不训练Empty臂。M82/M83旧结论不变，不重选旧checkpoint、不覆盖旧结果。

研究问题：当前密集adapter在空词下也会学习改变原生功能。M83显示固定Category历史时词内容的单步差异很小，但完整轨迹差异明显。检验共享参数的差分残差 `F + (D(x,q)-D(x,q_empty))` 是否能保留M82的整体收益，同时获得比仅在Empty时显式回退更有效的非空内容作用。这里不是声称已消除全部非语义成分；任何非空词都触发共同适配仍是可能的失败解释。

唯一新训练臂为Centered Category，从M82原始t0零初始化参数开始，130条DepthTrack Train拟合序列、同序列顺序、186694个跟踪转移、预期5798次优化。底座/Center Head冻结eval，Raw竞争和GT支持的同状态native KL保持原样（KL权重1），AdamW学习率1e-4、weight_decay1e-4、32帧梯度累积、clip1。五槽、mask、自动类别bank、空词向量不改；不加dropout、跨起点、记忆、恢复分支或Hann改动。全部后续crop/query/template来自预测，GT仅在当前状态提交后监督；不反传穿越时间或crop。

存储参数仍289154，最终线性层768维bias在差分中抵消，至多288386维影响该任务输出。两分支均保留梯度；先做delta差再加fused。适配器前向约增加一倍，完整模型算量不等同原M82。用零fused调用现有adapter取得delta，依赖已核查的现有实现仅在末尾加fused；不重写原交互结构。

对照为“仅Empty时显式归零、非空不变”的M82 mask-control。启动前必须核对M82 Category拟合130条及开发Category/Swapped输入的类别槽均非空、无dropout，且本轮初始可训练张量与M82逐一相等；因此非空控制路径可复用封存M82 Category/Swapped，不另训练一个控制。Empty控制对应原生。复用仅适用于这些固定非空输入，不声称真实错误文字会被自动识别。

预检：零参数101帧独立native递归bbox/score/query/template精确一致；非零M82参数配Empty再次101帧独立native一致；96帧实际拟合集、3次优化，检查有限损失/梯度、基座和buffer不变、参数确实学习、训练后Empty恒等。合成CPU前检中约1.46e-11的梯度残余是浮点累加，不是可用Empty任务梯度。前检权重不用于正式训练。

训练只保存最终完整pass作为评测权重；latest用于恢复，不能凭loss挑中间权重。完整开发22分三组：Category、同权重Empty、同权重Swapped；三组全部封存后才读取GT计算平均IoU、宏平均、IoU<=0.1帧、H10、逐序列损害和内容LOO。Empty仍实际完整运行，以检查其与原生的指标一致性；不是独立Empty训练。

预先规定接受条件：

1. 相对M82非空mask-control：按帧均值严格提高，宏均值不降、低重叠帧不增、H10不增（4项）。
2. 相对原生：按帧均值严格提高，宏均值不降、低重叠帧不增、H10不增、原生零H10序列无新增H10（5项）。
3. 相对同权重Swapped：按帧均值严格提高、宏均值不降、低重叠帧不增、H10不增（4项）。
4. 实际Empty完整结果与原生每条序列的IoU sum（绝对误差<=1e-8）、有效帧数、低重叠帧与H10一致（1项）。

总14项，报告全部正负结果。未通过就保留失败结论；不改门、不切Empty当主模型。初始词可能错误，Category优于Swapped仍仅支持既定自动类别条件作用，不自动证明正确类别语义或细粒度身份识别。此次无自动外部评测；最终仍须同一base/adapter/text/runtime完成DepthTrack Test、CDTB和full VOT。开发22及VOT低22均承认已反复使用。

方法审阅认为数学上可行但证据有限，建议先固定权重读出再决定训练。执行者已完成101帧固定M82权重CUDA接口读出（无后续GT、未提交替代状态），Empty精确native、非空相对native的Hann峰变化0/101；这只验证接口，不证明性能。本轮训练检验从零学习该参数化能否有效，不以该健康窗口为性能筛选。未追加又一轮全开发集固定旧权重读出，因为M83已完成此类状态分离诊断，而旧参数不是按中心化目标学得；这项取舍不应写成审阅者已批准性能。

估计单臂训练4–5小时、三组开发评测约1小时，按预检与实际吞吐更新。沿用既有远端STTrack环境，不安装包、不下载新权重，保留两套Qwen。只在完整代码审阅和前检完成后启动。
