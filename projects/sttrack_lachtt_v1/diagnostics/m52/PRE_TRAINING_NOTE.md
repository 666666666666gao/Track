# M52训练前实施与结果解释补充

在M52新状态数据采集仍运行、尚未进行新状态GT统计或任何M52训练时记录。本补充不修改正在运行的采集spec、样本时刻、模型、优化参数或任何数值门槛。

两组的结果承担两个问题：原缓存重复control检验额外训练，mixed检验新增策略状态。若mixed通过原生全部门槛，且相对control均值提高、低帧和H10均不增加，primary_pass才为真，收益可描述为本次状态数据对照的正证据。

若control单独通过原生全部门槛，它也是一个在DepthTrack Train真实训练、可供项目目标验证的权重。此时可以按原低22协议验证control，明确只称为额外训练收益；不能因为数据假设未通过而隐去一个达标的训练对照，也不能把control收益归给新状态。预先固定选择顺序：mixed满足原生与增量条件则选mixed；否则control满足原生全部条件则选control；否则两组都停止，不进入公开评测。程序分别输出primary_pass和advancing_arm，不混用两种结论。

原生门槛保持：mean IoU至少+0.01、低帧减少、H10不增加、至少3条均值改善、原生零失败序列不新增失败。没有降低门槛，没有根据新训练或开发结果挑选这一规则。两组都必须完整跑22条开发序列，不能只跑静态更好的一组。

执行顺序：CPU核验全部85份原特征、63份新特征和63份新轨迹的封存SHA后，才读既有监督标签；原2,101个目标标签应逐项复现M45。随后依次训练control和mixed，检查初始化、逻辑样本顺序和1,900步一致，验证实际tracker加载器与训练head输出一致，再执行两组各两个完整递归分片，最后统一分析。
